# Trackrr Sync - Chrome Extension

Automatic companion extension for Trackrr to extract Instagram Reel thumbnails, captions, and live likes using your authenticated browser session—with **zero API keys, zero rate limits, and no Meta developer account**.

---

## 🚀 10-Second Installation Guide

1. Open Google Chrome.
2. In the address bar, paste: `chrome://extensions` and press Enter.
3. In the top right corner, turn on the **Developer mode** toggle switch.
4. Click the **"Load unpacked"** button in the top left corner.
5. Select this folder:
   `C:\Users\ADMIN\Desktop\AntiGravity\FreelanceTracker-main\FreelanceTracker-main\trackrr-extension`
6. **Done!**
   - The Trackrr Sync icon will appear in your Chrome toolbar.
   - Open Trackrr (e.g. `http://localhost:5173`)—it will immediately detect the extension.
   - Now, every time you paste an Instagram Reel link, Trackrr will automatically fetch the HD thumbnail, likes, and caption!
